# 📦 Optional NPM Setup

If you want to convert the project into a basic npm-managed frontend project:

```bash
npm init -y
```

Then install a local development server:

```bash
npm install --save-dev live-server
```

Add the following script to `package.json`:

```json
{
  "scripts": {
    "dev": "live-server"
  }
}
```

Then run:

```bash
npm run dev
```

The website will launch through the local development server.

> Note: npm is optional because this portfolio is intentionally built as a lightweight static HTML/CSS/JavaScript project.
