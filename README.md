# ✨ UI / UX PRINCIPLES

The projects were approached with a focus on practical interface design.

### 🎯 Visual Hierarchy

Important information should be visually clear and easy to find.

### 🖱️ Interaction

Buttons and interactive elements should provide clear feedback.

### ⚡ Responsiveness

Interfaces should adapt instead of breaking across screen sizes.

### 🎨 Consistency

Typography, spacing, colors and interaction patterns should feel cohesive.

### 🧩 Simplicity

The interface should remain understandable instead of adding complexity without purpose.
